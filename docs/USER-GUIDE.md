# 땡땡엑셀 사용설명서

> `xmux`는 저장소와 개발 프로젝트의 이름입니다. Excel 리본과 작업창에서 사용하는
> 제품명은 **땡땡엑셀**입니다.

## 1. 땡땡엑셀이 하는 일

땡땡엑셀은 선택한 셀의 수식이 참조하는 범위를 작업창에서 바로 보여줍니다. 다른
시트를 참조하는 수식도 현재 시트를 벗어나지 않고 확인하고 수정할 수 있습니다.

예를 들어 `Main!B2`의 수식이 다음과 같다면:

```excel
=SUM(Data!B2:D5)+Main!A1*Data!F1
```

각 참조에 색상이 표시되고 `Data!B2:D5`, `Main!A1`, `Data!F1`의 실제 값이
작업창 그리드에 나타납니다.

## 2. 작업창 열기

1. Excel을 실행합니다.
2. **홈 > 땡땡엑셀** 버튼을 누릅니다.
3. Excel에서 확인할 셀을 선택합니다.

작업창 상단에는 **시트**와 **대화** 탭이 있습니다.

- **시트**: 수식과 참조 범위를 확인하고 수정
- **대화**: 선택한 셀 맥락으로 AI에게 작업 요청

## 3. 시트 탭

### 3.1 수식과 계산 과정 확인

수식의 각 참조는 서로 다른 색상으로 표시됩니다. 긴 수식은 줄바꿈되어 전체 내용이
보입니다.

계산 설명의 단계 번호와 수식 안의 참조 번호는 구분되어 표시됩니다. 실제 결과와
숫자 데이터에는 천 단위 쉼표가 적용됩니다.

참조 주소는 항상 시트명을 포함한 형태로 표시됩니다.

```text
Data!B2:D5
'Far Away'!B4:D20
```

### 3.2 참조 조작

| 동작 | 결과 |
|---|---|
| 참조 클릭 | 작업창에서 해당 참조를 엽니다. |
| 참조 더블클릭 | Excel에서 해당 시트와 범위로 이동합니다. |
| `Alt`+참조 클릭 | 정확한 `시트!주소`를 대화 탭에 첨부합니다. |
| `←` / `→` | 이전 또는 다음 참조로 이동합니다. |
| `Enter` | 현재 참조를 Excel 선택 범위로 이동하고 고정합니다. |
| `Delete` / `Backspace` | 활성 참조를 수식에서 삭제합니다. |

참조 삭제는 키보드로만 수행하며 별도의 삭제 버튼은 없습니다.

### 3.3 참조 그리드

- 셀 클릭: 셀 선택
- 드래그: 범위 선택
- 선택한 셀 재클릭 또는 셀 더블클릭: 값 편집
- 그리드 가장자리까지 드래그: 시트를 계속 스크롤
- 시트 탭이 많을 때 탭 레일 드래그: 좌우 이동

시트 탭 이동용 화살표 버튼은 제공하지 않습니다.

다른 범위를 선택하면 다음 작업을 실행할 수 있습니다.

- **이 참조 바꾸기**: 현재 수식 참조를 선택한 범위로 교체
- **수식 끝에 더하기**: 선택한 범위를 `+`로 연결
- **복사**: 시트명이 포함된 정확한 범위 주소 복사

`Esc`를 한 번 누르면 임시 선택을 취소하고 원래 참조를 복원합니다. 다시 누르면
처음 확인하던 셀로 돌아갑니다.

### 3.4 여러 셀 선택

Excel에서 여러 셀을 선택하면 같은 작업창 그리드에서 범위를 확인할 수 있습니다.
Excel이 계산할 수 있는 경우 개수, 합계와 평균도 표시됩니다.

## 4. 셀 값과 수식 수정

작업창에서 수정한 셀 값, 범위와 수식 변경은 모두 되돌리기 기록에 포함됩니다.

- `Ctrl`/`Cmd`+`Z`: 되돌리기
- `Ctrl`+`Y` 또는 `Ctrl`/`Cmd`+`Shift`+`Z`: 다시 실행

헤더의 단일 버튼은 현재 상태에 따라 **되돌리기** 또는 **다시 실행**으로 바뀝니다.
되돌리기·다시 실행 메시지와 임시 **다시 실행** 텍스트 버튼은 5초 후 사라집니다.

Excel에서 셀을 직접 편집 중이면 작업창에 다음 메시지가 표시됩니다.

```text
편집 중 · Enter나 Esc를 누르면 갱신
```

편집을 확정하거나 취소하면 작업창이 다시 갱신됩니다.

## 5. 대화 탭

### 5.1 최초 연결 설정

대화 탭의 설정에서 다음 항목을 입력합니다.

- **API 키**
- **서버 주소**
- **모델 ID**

기본 서버 주소:

```text
https://ai.kdb.co.kr:32210/api
```

**연결 확인**을 눌러 정상 연결 여부를 확인합니다. API 키는 작업창의 현재 사용자
저장소에만 저장되며 Excel 통합 문서에는 기록되지 않습니다.

### 5.2 Excel 맥락 첨부

다음 정보가 대화 요청에 포함될 수 있습니다.

- 시트 목록
- 선택한 셀과 수식
- 수식 결과와 참조 요약
- 선택 셀 주변의 실제 값과 추정 헤더
- `Alt`+클릭으로 첨부한 정확한 `시트!주소`

첨부 칩의 **선택 범위 첨부 해제**를 누르면 해당 범위를 요청에서 제외할 수
있습니다.

### 5.3 AI 제안 적용

AI가 제안한 셀 변경에는 **적용**과 **취소** 버튼이 표시됩니다.

- **적용** 전에는 통합 문서가 변경되지 않습니다.
- 적용된 변경은 `AI 제안 N건`으로 되돌리기 기록에 남습니다.
- 잘못 적용했으면 일반 되돌리기 기능으로 복구할 수 있습니다.

## 6. 스킬 사용

입력창에서 `/`를 입력하거나 스킬 버튼을 눌러 사용할 스킬을 선택합니다.

기본 제공 스킬:

- 3개 재무제표 모델
- Excel 감사
- 데이터 정리
- 비교기업 분석
- DCF 모델
- LBO 모델
- 모닝 노트
- 스킬 만들기

선택한 스킬은 GPT 서브 에이전트에 해당 워크플로와 Excel 맥락을 함께 전달합니다.
스킬을 사용하지 않으려면 **스킬 해제**를 누릅니다.

### 사용자 스킬 만들기

1. **스킬 만들기**를 선택합니다.
2. 스킬 이름, 실행 트리거와 지침을 입력합니다.
3. 생성된 제안 카드를 확인합니다.
4. **로컬에 저장**을 눌러 저장하거나 **버리기**를 눌러 취소합니다.

사용자 스킬은 자동 저장되지 않습니다. 저장된 스킬은 **내 스킬**로 표시되며 현재
PC의 사용자 저장소에만 남습니다. Excel 파일이나 배포 ZIP에 포함되지 않습니다.

## 7. 외부 통합 문서 참조

Windows 데스크톱 Excel의 Office.js 추가 기능은 다른 통합 문서의 임의 범위를
직접 읽거나 수정할 수 없습니다.

외부 참조가 있는 경우 땡땡엑셀은 현재 셀에 저장된 Excel 계산 결과를 표시합니다.
이는 외부 파일의 개별 셀 값이나 최신 상태를 보장하지 않습니다.

## 8. 상태와 오류 메시지

| 메시지 | 의미 또는 조치 |
|---|---|
| `갱신 중` | 선택한 셀 정보를 읽고 있습니다. |
| `고정됨` | 현재 참조 화면을 유지합니다. 배지를 누르면 선택을 다시 따라갑니다. |
| `<범위> 복사됨` | 정확한 시트·범위 주소가 클립보드에 복사되었습니다. |
| `편집 중 · Enter나 Esc를 누르면 갱신` | Excel 셀 편집을 먼저 끝냅니다. |
| `수식이 아닌 값입니다.` | 선택한 셀에 수식이 없습니다. |
| `참조 없음` | 다른 셀을 참조하지 않는 수식입니다. |
| `Excel에서만 동작합니다.` | 브라우저가 아닌 Excel에서 작업창을 엽니다. |

## 9. 자주 겪는 문제

### 작업창이 비어 있음

Excel에서 셀을 선택합니다. 첫 화면에 `Excel에서 셀을 선택해 보세요`가 표시되면
정상입니다.

### 선택하거나 편집한 값이 갱신되지 않음

현재 셀이 편집 모드인지 확인하고 `Enter` 또는 `Esc`를 누릅니다.

### 리본에 땡땡엑셀 버튼이 없음

Excel을 완전히 종료했다가 다시 실행합니다. 계속 보이지 않으면
[`INSTALL.md`](INSTALL.md)의 개발자 추가 기능 등록 절차를 다시 확인합니다.

### 작업창이 열리지 않음

일반 PowerShell에서 서비스를 확인합니다.

```powershell
& "$env:LOCALAPPDATA\DdotExcel\manage.ps1" status
```

자세한 설치·서비스 문제 해결은 [`INSTALL.md`](INSTALL.md)를 참고합니다.
